# Methods and formulae

This file summarises the transformations and evaluation formulae implemented in `03_Code/model_analysis.py`. The code is the authoritative executable specification.

## Outcome transformation

Models are fitted to the transformed outcome

$$y_i^{*}=\log(1+y_i),$$

where $y_i$ is total energy consumption (TEC). Predictions are returned to the original scale using

$$\hat{y}_i=\exp(\hat{y}_i^{*})-1.$$

## Data split and optimisation

- Random train/test split: 80%/20%, with shuffling and random seed 42.
- Hyperparameter optimisation: Optuna tree-structured Parzen estimator.
- Candidate models: AdaBoost, XGBoost, random forest, GBDT, CatBoost, and LightGBM.
- Trials: 100 per model, including 10 start-up trials.
- Within-training-set validation: shuffled five-fold cross-validation with random seed 42.
- Optimisation objective: mean cross-validated root mean square error (RMSE), minimised.

## Main performance metrics

For $n$ observations with outcomes $y_i$, predictions $\hat{y}_i$, and mean outcome $\bar{y}$:

$$\mathrm{RMSE}=\sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2},$$

$$\mathrm{MAE}=\frac{1}{n}\sum_{i=1}^{n}|y_i-\hat{y}_i|,$$

$$R^2=1-\frac{\sum_{i=1}^{n}(y_i-\hat{y}_i)^2}{\sum_{i=1}^{n}(y_i-\bar{y})^2},$$

and variance accounted for is reported as a percentage:

$$\mathrm{VAF}=\left(1-\frac{\operatorname{Var}(y-\hat{y})}{\operatorname{Var}(y)}\right)\times100.$$

The analysis output files generated by the code also contain MSE, median absolute error, MAPE, symmetric MAPE, explained variance, ratio of performance to deviation, and Nash–Sutcliffe efficiency.

## Interpretation analyses

- SHAP values are computed for the selected best-performing model and summarised globally, by province, by region, and by sample.
- One-hot-encoded regional SHAP components are summed to a single `Region` contribution for reporting.
- Partial-dependence calculations are used to describe model-implied marginal response patterns. They are interpreted as predictive associations, not causal effects.

## Reproducibility boundary

The workflow is a random train/test prediction study. It does not implement a temporal hold-out, leave-province-out validation, feature-ablation study, or causal identification design.
